# dotsquares-travel

## About Us Page

This project includes an About Us page featuring a "Meet Our Travel Experts" team section.

### Team Section

- Location: `src/components/TeamSection/`
- Displays a responsive grid of team member cards (photo, name, role, short bio).
- Demo data lives in `src/data/teamMembers.js` and currently includes six team members.
- Grid layout adapts from 1 column (mobile) up to 4 columns (desktop) for a consistent, responsive design.
